# Знахідки з розвідки API (2026-09-26)

Скрипт: `python3 explore/explore_api.py [--query ... --search-lang .. --langs ..]`

1. **Ліміт запитів (HTTP 429).** Після ~10 швидких запитів API блокує, `Retry-After` доходив до 43 с.
   → Потрібні пауза між запитами, повтор з очікуванням і **кеш на диску**.
2. **Тема → статті через Wikidata працює.** `астрономія` → Q333 → uk/pl/cs/en назви.
   Але серед кандидатів є «Астрономія (клас у Гоґвортсі)» та наукові статті → перший результат не завжди правильний.
3. **Статті може не бути.** «Intermittent fasting» (Q1666254) не має польської статті, хоча це перший приклад з кейсу.
   Термін лише згадується всередині інших статей. → Навичка має явно казати «даних немає» і пропонувати альтернативи.
4. **Сезонність.** uk «Астрономія»: вересень у 3–5 разів вищий за звичайний місяць (початок навчального року).
   Порівнювати треба рік до року, а не місяць до місяця.
5. **Загальний спад Вікіпедії.** Уся uk-Вікіпедія: −24.6% за рік. «Астрономія» −59.6% в абсолюті, але −45.5% після нормалізації.
   → Без нормалізації висновок «інтерес падає» перебільшений.
6. **Боти.** uk «Астрономія» за 12 міс: user 6730, automated 2612, spider 2869 → майже половина трафіку не людська.
   Завжди `agent=user`.
7. **Малі обсяги.** uk «Астрономія» ~15 переглядів/день → 1 шкільний клас дає «сплеск». Потрібен поріг довіри за обсягом.
